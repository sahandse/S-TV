# 📺 S-TV | تلویزیون زنده، ساده و جمع‌وجور

دوست داری کانال‌های تلویزیونی کشورهای مختلف رو بدون نصب برنامه‌های پیچیده ببینی؟ **S-TV** یه وب‌اپ فارسی و رایگانه که کانال‌ها رو مرتب جلوت می‌ذاره. کانال رو انتخاب کن و تماشا رو شروع کن! ✨

> همه‌ی کانال‌ها لزوماً همیشه قابل پخش نیستن. S-TV لینک‌های عمومیِ ثبت‌شده در فهرست IPTV رو نمایش می‌ده؛ باز شدن تصویر به اتصال اینترنت، مرورگر، وضعیت خود کانال و محدودیت‌های پخش بستگی داره.

## 🌟 چه چیزهایی داخل برنامه داریم؟

- 📡 فهرست کانال‌های واقعی، مرتب‌شده بر اساس کشور و دسته‌بندی
- 🔎 جستجوی سریع با نام کانال
- ❤️ ذخیره کانال‌های موردعلاقه روی همین دستگاه
- 🕒 نمایش کانال‌هایی که اخیراً تماشا کردی
- 📺 **حالت تلویزیون** با پخش‌کننده بزرگ و لیست کانال‌ها کنار تصویر
- 🎮 حرکت در رابط با کلیدهای جهت و Enter؛ پشتیبانی آزمایشی از Gamepad API در مرورگرهای سازگار
- 📅 نمایش برنامه فعلی و بعدی، **فقط زمانی که اطلاعات واقعی EPG در دسترس باشه**
- 🌙 محیط تاریک و خلوت، مناسب تماشا در شب
- 📱 طراحی سازگار با موبایل، تبلت و صفحه‌نمایش بزرگ

## 🚀 چطوری استفاده کنم؟

1. سایت S-TV رو باز کن.
2. از صفحه اصلی روی **حالت تلویزیون** بزن یا از بخش کشورها/دسته‌بندی‌ها کانال پیدا کن.
3. اسم کانال رو انتخاب کن تا پخش شروع بشه.
4. اگه پخش خودکار مسدود بود، روی **شروع پخش** بزن.
5. کانال‌های دلخواه رو با ❤️ ذخیره کن تا بعداً راحت پیداشون کنی.

**آدرس حالت تلویزیون در GitHub Pages:** `https://sahandse.github.io/S-TV/#/tv`

## 🎮 استفاده روی تلویزیون، PS4 و PS5

صفحه «حالت تلویزیون» برای فاصله بیشتر از نمایشگر طراحی شده: دکمه‌های بزرگ‌تر، فوکوس مشخص، و لیست کانال کنار تصویر.

- **تلویزیون و کامپیوتر:** با کلیدهای جهت حرکت کن، با Enter انتخاب کن؛ PageUp و PageDown کانال رو عوض می‌کنن.
- **دسته بازی:** در مرورگرهایی که Gamepad API رو پشتیبانی کنن، حرکت با D-pad/آنالوگ و انتخاب با دکمه اصلی به‌شکل آزمایشی فعاله. کارکرد همه دسته‌ها و مرورگرها تضمین نشده.
- **PS4:** امکان دسترسی به وب از مرورگر دستگاه به نسخه و شرایط کنسول بستگی داره؛ پخش HLS همه کانال‌ها تضمین‌شده نیست.
- **PS5:** مرورگر عمومی مستقل در دسترس نیست. پس نمی‌شه قول داد که سایت روی PS5 مثل یک اپ رسمی باز یا نصب بشه.

**مهم:** این پروژه اپلیکیشن رسمی PlayStation نیست و روی کنسول واقعی هنوز آزمایش و تأیید نشده.

## 📱 نصب روی گوشی

**اندروید:** سایت رو داخل Chrome باز کن و از منو «Install app» یا «Add to Home screen» رو انتخاب کن (در صورت پشتیبانی مرورگر).

**آیفون:** داخل Safari، دکمه Share رو بزن، بعد **Add to Home Screen** رو انتخاب کن.

پخش کانال‌ها اینترنت می‌خواد؛ آفلاین فقط ممکنه پوسته سایت باز بشه.

## ❓ چند سؤال پرتکرار

**همه کانال‌ها پخش می‌شن؟** نه لزوماً. لینک بعضی کانال‌ها از دسترس خارج می‌شه یا در بعضی کشورها و مرورگرها محدودیت داره.

**اطلاعات برنامه فعلی و بعدی از کجا میاد؟** فقط از زمان‌بندی واقعی XMLTV برای کانال‌های دارای راهنمای معتبر. نبودِ جدول برنامه با اطلاعات ساختگی پر نمی‌شه.

**باید حساب بسازم؟** نه؛ علاقه‌مندی‌ها و آخرین تماشاها روی مرورگر دستگاهت ذخیره می‌شن.

**رایگانه؟** خود وب‌اپ برای استفاده رایگانه؛ هزینه اینترنت طبق سرویس اینترنت خودته.

## 🛠 اجرای پروژه روی کامپیوتر

برای توسعه به Node.js نسخه 20 یا بالاتر و npm نیاز داری:

```bash
git clone https://github.com/sahandse/S-TV.git
cd S-TV
npm ci
npm run dev
```

برای بررسی خروجی انتشار:

```bash
npm run build
npm run preview
```

پروژه با **React + TypeScript + Vite + Tailwind CSS** ساخته شده. داده‌های فهرست کانال از پروژه عمومی [iptv-org](https://github.com/iptv-org) دریافت می‌شن. وجود لینک به معنی تضمین دسترسی یا مجوز بازپخش نیست؛ حقوق و محدودیت‌های هر شبکه باید رعایت بشن.
